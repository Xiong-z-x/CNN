# 暗光目标检测项目交接说明

这份文档是给后续继续撰写报告的人或模型助手准备的快速交接材料。目标是让不了解上下文的人，也能在最短时间内理解项目结构、实验流程、最终结果和适合写进报告的重点。

## 1. 项目目标

本项目围绕“暗光目标检测”课程作业展开，设计并实现了两条纯 CNN 检测流水线：

- 基础方案：`CLAHE + YOLOv5su`
- 前沿方案：`Zero-DCE++ + YOLO26n`

整体思路是：

1. 以 `PASCAL VOC 2007` 为原始目标检测数据集。
2. 通过离线脚本构造暗光版本 `VOC_Dark`。
3. 分别使用传统增强和深度增强生成两套增强数据。
4. 基于官方预训练权重进行迁移学习和评估。

## 3. 最终采用的实验结果

最终保留的是 30 epoch 微调结果，而不是后面追加训练的 `imgsz=800` 版本。

### 3.1 基础方案

- 方案：`CLAHE + YOLOv5su`
- 最终结果：
  - `mAP50 = 0.7472140521000403`
  - `mAP50-95 = 0.5234947181126162`

### 3.2 前沿方案

- 方案：`Zero-DCE++ + YOLO26n`
- 最终结果：
  - `mAP50 = 0.7344471110191553`
  - `mAP50-95 = 0.5324027423592027`

### 3.3 无微调与微调的对比

| 方案 | 无微调 mAP50 | 微调后 mAP50 | 无微调 mAP50-95 | 微调后 mAP50-95 |
|---|---:|---:|---:|---:|
| CLAHE + YOLOv5su | 0.0869 | 0.7472 | 0.0694 | 0.5235 |
| Zero-DCE++ + YOLO26n | 0.0828 | 0.7344 | 0.0661 | 0.5324 |

最重要的结论：

- 直接拿预训练检测器在暗光域上推理，指标很低。
- 在增强后数据上对检测器进行微调后，性能显著提升。
- 微调是这个任务真正起决定作用的步骤。

## 4. 结果如何解读

### 4.1 两条主线的结论

- 基础方案在 `mAP50` 上略高，说明总体检出能力更强。
- 前沿方案在 `mAP50-95` 上略高，说明在更严格的定位标准下边界框质量更稳。
- 两条方案都成立，而且结果非常接近，这反而适合报告写作，因为可以自然得出“传统增强和深度增强在暗光检测中各具优势”的结论。

### 4.2 不建议保留的实验

后续还尝试过继续训练前沿方案：

但结果没有进一步提升，因此不建议把它作为最终结果写进报告。

## 8. 报告最值得写的结论

如果只保留最核心的三条结论，可以直接用：

1. 暗光增强与目标检测组合成的级联流水线是有效的。
2. `CLAHE + YOLOv5su` 在 `mAP50` 上最优，`Zero-DCE++ + YOLO26n` 在 `mAP50-95` 上最优。
3. 相比直接使用预训练权重推理，针对暗光域进行微调能够带来决定性的性能提升。
